# LabelPaw 项目架构分析

## 整体架构

```
用户操作
    │
    ▼
main.py (主控窗口) ──── 事件分发 ────→ core/ (核心逻辑层)
    │                                        │
    │  import                                 │
    ├── ui/ (界面层) ──── setupUi() ────→     ├── canvas.py  (画布交互)
    │   ├── ui_main_window.py  (.ui 编译)     ├── shapes.py  (标注图形)
    │   ├── main_window.py     (自定义控件)    ├── sam_client.py (SAM推理)
    │   ├── author_info.py     (作者弹窗)      ├── yolo_predictor.py (YOLO推理)
    │   ├── template_dialog.py (模板编辑)      ├── exporter.py (数据导出)
    │   ├── model_selector_dialog.py (模型选择)  ├── pose_template.py (骨架模板)
    │   ├── train_dialog.py  (YOLO训练)       ├── pose_template.py (骨架模板)
    │   ├── resources.qrc      (资源清单)       ├── translations.py (中英文映射)
    │   ├── resources_rc.py   (编译资源)        └── geometry.py (几何算法)
    │   ├── theme.py           (主题样式)
    │   └── style.qss          (样式表)
    │
    │  import
    ├── utils/
    │   └── message.py         (通知弹窗)
    │
    │  import
    └── main_dataset_tool.py   (数据集批量处理)
```

## 文件调用关系（谁引用了谁）

### 1. `main.py` — 程序入口

```
main.py 引用的模块：
├── ui.ui_main_window.Ui_MainWindow         ← 主窗口布局 (pyside6-uic 生成)
├── ui.main_window.TemplateSelectorWidget   ← 骨架模板选择器
├── ui.main_window.FormatSelectorWidget     ← 标注格式下拉菜单
├── ui.author_info.AuthorInfoDialog         ← 作者信息弹窗
├── ui.template_dialog.SkeletonTemplateDialog ← 骨架模板编辑器
├── ui.model_selector_dialog.ModelSelectorDialog ← 模型选择弹窗
├── ui.train_dialog.TrainDialog / TrainWorker  ← YOLO 训练对话框
├── ui.theme.DARK_THEME / LIGHT_THEME       ← 亮色/暗黑主题 QSS
├── core.canvas.Canvas / CanvasMode         ← 画布场景
├── core.sam_client.SAMClient / SAM_MODEL_MAP ← SAM 模型客户端
├── core.exporter.Exporter                  ← 标注数据导出
├── core.shapes.*                           ← 标注图形(矩形/多边形/关键点/OBB)
├── core.pose_template.TemplateManager      ← 骨架模板管理
├── core.yolo_predictor.YoloPredictorWorker ← YOLO 推理线程
├── utils.message.DialogOver                ← 通知弹窗
├── main_dataset_tool.DatasetToolWindow     ← 数据集处理窗口
├── ui.resources_rc                         ← Qt 资源系统 (pyside6-rcc 编译)
└── triton                                  ← CUDA 编译器 (延迟导入)
```

### 2. `core/sam_client.py` — SAM 模型客户端

```
被 main.py 引用: SAMClient, SAM_MODEL_MAP
依赖的外部模块:
├── torch / numpy / cv2               ← 深度学习 + 图像处理
├── PIL.Image                         ← 图片加载
├── sam3.model_builder                ← SAM3 模型构建 (QThread 内延迟加载)
├── sam2.build_sam / sam2 predictor   ← SAM2 模型构建 (可选)
内部类:
├── Sam3ModelLoadWorker(QThread)      ← SAM3 模型加载线程
├── Sam3InferenceWorker(QThread)      ← SAM3 推理线程
│   ├── request_inference(x, y, is_click)  ← 点击推理
│   └── request_text_inference(prompt)     ← 文本提示推理
├── Sam2ModelLoadWorker(QThread)      ← SAM2 模型加载线程
├── Sam2InferenceWorker(QThread)      ← SAM2 推理线程
└── SAMClient(QObject)                ← 统一客户端，管理模型切换
```

### 3. `core/canvas.py` — 画布场景

```
被 main.py 引用: Canvas, CanvasMode
依赖的外部模块:
├── PySide6.QtWidgets.QGraphicsScene  ← 父类
├── core.shapes.*                     ← 所有标注图形类
内部类:
├── CanvasMode                        ← 标注模式枚举 (RECT/POLY/POINT/RBOX)
└── Canvas(QGraphicsScene)            ← 画布场景
    ├── 鼠标事件: mouseMove → SAM 推理 / 鼠标悬停预览
    ├── 鼠标事件: mousePress → SAM 确认 / 选中/绘图
    ├── 鼠标事件: mouseRelease → 完成绘制
    ├── 键盘事件: 删除/撤销/旋转框微调
    └── handle_sam_result()           ← 处理 SAM 推理结果
```

### 4. `core/shapes.py` — 标注图形

```
被 canvas.py / exporter.py / main.py 引用
依赖的外部模块:
├── PySide6.QtWidgets.QGraphicsItem   ← 父类
├── PySide6.QtGui.QPainter            ← 自绘
├── core.translations.KEYPOINT_TRANSLATIONS  ← 关键点名称翻译
```

## 数据流（运行时调用链）

### 标注流程

```
用户选择图片
    → main.on_file_selected()
        → canvas.load_image(path)        # 加载图片到画布
        → canvas.clear_shapes()          # 清除旧标注
        → load_annotations(path)         # 加载已有标注
            → _load_json / _load_yolo / _load_xml
        → sam_client.set_image(path)     # SAM 特征提取

用户绘制标注
    → canvas.mousePressEvent
        → (SAM 模式) sam_client.request_inference()
            → Sam3InferenceWorker.run() → model.predict_inst()
            → signal: inference_result → canvas.handle_sam_result()
            → signal: shape_drawn → main.handle_new_shape()
        → (手动模式) 创建 shape 对象 → shape_drawn
    → canvas.mouseReleaseEvent
        → signal: state_changed → main.push_state()

保存标注
    → main.save_annotation(format)
        → Exporter.extract_shapes(scene)  # 提取所有 shape
        → Exporter.save_json / save_yolo / save_xml
```

### SAM3 模型加载流程

```
main.on_model_selected("sam3")
    → SAMClient.load_model_by_key("sam3")
        → QThread: Sam3ModelLoadWorker.run()
            → [延迟导入] from sam3.model_builder import build_sam3_image_model
            → model = build_sam3_image_model(weight_path)
            → model.to("cuda")
            → processor = Sam3Processor(model)
        → signal: loaded → _on_sam3_loaded()
            → 创建 Sam3InferenceWorker (推理线程)
            → 绑定 signal: result_ready → canvas.handle_sam_result
```

## 关键设计决策

1. **多线程模型推理** — SAM/SAM2/YOLO 推理在 QThread 中执行，不阻塞 UI
2. **延迟导入** — triton/sam3 在 QThread 内延迟导入，防止 DLL 冲突阻塞模块加载
3. **快照式撤销** — 每次修改保存完整标注快照（最多 20 步），完全重建画布
4. **SVG 图标着色** — 通过 QPainter 运行时重绘 SVG 图标颜色，支持主题切换
5. **.ui + pyside6-uic 编译** — 布局在 Qt Designer 中编辑，编译生成 Python 代码
6. **.qrc 资源系统** — 图标/QSS 集中管理，运行时脱离文件系统依赖
